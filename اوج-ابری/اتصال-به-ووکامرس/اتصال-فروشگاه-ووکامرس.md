<p>در این راهنما فروشگاه ووکامرس خود را به اوج ابری وصل می‌کنید. فروشگاه شما روی وردپرس است. پس از اتصال، اوج ابری می‌تواند اطلاعات فروشگاه را دریافت کند و بعضی اطلاعات را به آن بفرستد. برای این کار به «توکن وردپرس» نیاز دارید. توکن یک رمز طولانی است که از پنل وردپرس فروشگاه ساخته می‌شود. «دامنه» نشانی اصلی سایت شماست، مثل example.com.</p>

<h2>پیش از شروع</h2>
<ul>
<li>فروشگاه ووکامرس شما روی وردپرس باشد.</li>
<li>روی وردپرس فروشگاه، افزونه‌ای با نسخه ۱.۳.۴ یا جدیدتر نصب شده باشد.</li>
<li>به پنل وردپرس فروشگاه دسترسی داشته باشید. توکن را از آن‌جا می‌گیرید.</li>
<li>در اوج ابری، منوی «کانکتور وردپرس» را ببینید. اگر این منو را نمی‌بینید، دسترسی شما برای این کار کافی نیست.</li>
<li>پنل وردپرس توکن را فقط یک بار نشان می‌دهد، هنگام ساختن اتصال یا تعویض توکن. پس توکن را همان موقع کپی کنید.</li>
<li>اگر توکن را از دست داده‌اید، در پنل وردپرس توکن تازه بسازید.</li>
</ul>

<h2>مراحل اتصال</h2>
<ol>
<li>در اوج ابری، برنامه «کانکتور وردپرس» را باز کنید. صفحه کانکتور وردپرس باز می‌شود.</li>
<li>در منوی «کانکتور وردپرس»، روی «بک‌اندها» کلیک کنید. فهرست اتصال‌های وردپرس باز می‌شود. هر ردیف یک فروشگاه متصل است.</li>
<li>روی دکمه «جدید» کلیک کنید. فرم خالی اتصال باز می‌شود.</li>
<li>در کادر «نام»، نامی برای این فروشگاه بنویسید.</li>
<li>در کادر «دامنه وردپرس»، دامنه فروشگاه را بنویسید. فقط نام سایت را بنویسید، مثلاً example.com.</li>
<li>کادر «آدرس پایه API (اختیاری)» را خالی بگذارید. در این حالت اوج ابری آدرس فروشگاه را از روی دامنه می‌سازد.</li>
<li>در کادر «توکن وردپرس»، توکنی را که کپی کرده‌اید بچسبانید. متن توکن با نقطه پوشانده می‌شود.</li>
<li>روی «ذخیره» کلیک کنید. اتصال ذخیره می‌شود.</li>
<li>در بالای فرم، روی دکمه «تست اتصال» کلیک کنید. پیام سبز «موفق» نمایش داده می‌شود.</li>
</ol>

<h2>نتیجه</h2>
<p>پیام «موفق» را می‌بینید. متن پیام «به افزونه ... متصل شد.» یا «اتصال با موفقیت انجام شد.» نمایش داده می‌شود. اتصال آماده است. برای وارد کردن اطلاعات فروشگاه، راهنمای «ورود محصولات و سفارش‌ها از فروشگاه ووکامرس» را دنبال کنید.</p>

<h2>اگر … انجام نشد</h2>
<ul>
<li>اگر پیام «دامنهٔ وردپرس باید یکتا باشد.» را دیدید، این دامنه قبلاً در یک اتصال دیگر ثبت شده است. «بک‌اندها» را باز کنید، اتصال قبلی همین دامنه را پیدا کنید و همان اتصال را ادامه دهید.</li>
<li>اگر پیام «بک‌اند وردپرس باید نام داشته باشد.» را دیدید، کادر «نام» را پر کنید و دوباره روی «ذخیره» کلیک کنید.</li>
<li>اگر پیام «دامنهٔ وردپرس باید فقط نام میزبان باشد…» را دیدید، دامنه را پاک کنید. فقط نام سایت را بنویسید، مثلاً example.com. سپس روی «ذخیره» کلیک کنید.</li>
<li>اگر پیام «آدرس پایه API نباید شامل … باشد.» را دیدید، کادر «آدرس پایه API (اختیاری)» را خالی کنید یا آدرس را فقط تا ریشه سایت بنویسید. سپس روی «ذخیره» کلیک کنید.</li>
</ul>
