# راهنمای محصولات آموت

به مجموعه راهنماهای محصولات **آموت** خوش آمدید.

در این مخزن می‌توانید آموزش‌ها و راهنماهای مربوط به استفاده از سرویس‌ها و محصولات آموت را به‌صورت دسته‌بندی‌شده مشاهده کنید.

## محصولات

راهنماها در حال حاضر برای محصولات زیر ارائه شده‌اند:

- **پیامک**
- **آوانک**
- **اوج ابری**

هر محصول شامل بخش‌ها و موضوعات مختلفی است تا بتوانید سریع‌تر به آموزش موردنظر خود دسترسی پیدا کنید.

## ساختار راهنماها

راهنماها بر اساس محصول و موضوع دسته‌بندی شده‌اند.

برای مثال:

```text
پیامک/
└── ارسال-تکی-و-گروهی/
    └── ارسال-به-یک-شماره.md
```

در این نمونه:

- `پیامک` نام محصول است.
- `ارسال-تکی-و-گروهی` موضوع راهنما است.
- `ارسال-به-یک-شماره` آموزش موردنظر است.

## چگونه از راهنماها استفاده کنیم؟

ابتدا محصول موردنظر خود را انتخاب کنید، سپس وارد بخش مرتبط شوید و راهنمای موردنیاز را باز کنید.

برای مثال اگر به دنبال آموزش ارسال پیامک به یک شماره هستید:

```text
پیامک → ارسال تکی و گروهی → ارسال به یک شماره
```

## فرمت راهنماها

تمام راهنماها با فرمت Markdown نگهداری می‌شوند و می‌توانید آن‌ها را مستقیماً در GitHub مطالعه کنید.

هر راهنما تلاش می‌کند مراحل انجام کار را به‌صورت ساده، مرحله‌به‌مرحله و قابل فهم توضیح دهد.

## محصولات و موضوعات

### پیامک

راهنماهای مرتبط با سرویس پیامک آموت، از جمله ارسال پیامک و قابلیت‌های مرتبط.

### آوانک

راهنماهای سرویس پیام صوتی آوانک، شامل ارسال پیام صوتی، مدیریت مخاطبین، سوابق ارسال، اعتبار و سایر امکانات.

### اوج ابری

راهنماهای مربوط به محصولات و سرویس‌های اوج ابری، شامل امکانات مدیریتی، کاربران، پروژه‌ها، گزارش‌ها، ارتباط با مشتریان و سایر قابلیت‌های سامانه.

## پیدا نکردن راهنمای موردنظر

اگر راهنمای موردنظر خود را پیدا نکردید، ممکن است آن آموزش هنوز به این مجموعه اضافه نشده باشد.

می‌توانید از طریق کانال‌های پشتیبانی آموت موضوع موردنظر خود را مطرح کنید تا راهنمایی لازم را دریافت کنید.

## درباره این مجموعه

این مجموعه با هدف ساده‌تر کردن استفاده از محصولات آموت و فراهم کردن دسترسی سریع به آموزش‌های کاربردی ایجاد شده است.

راهنماها به‌مرور تکمیل و به‌روزرسانی می‌شوند.
